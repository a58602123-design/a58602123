# 高鐵公車一鍵搭車｜長輩版 v4

免費、免登入、iPhone/Android 雙平台共用的網頁 App（PWA）。

## 主要功能
- **高鐵南港→雲林→南公館**：高鐵＋7102／7102A／7102B＋7111；列出可轉乘的多組組合。
- **南公館→雲林→高鐵南港**：7111＋7102／7104＋高鐵；列出可轉乘的多組組合。
- 「現在以後、早上、下午」大按鈕。預設只列出等候較合理的組合；超過約 90 分鐘的久候留在「看更多」。轉車少於 30 分鐘仍會列出，並標示風險。
- 各組列出高鐵車次、每段公車車號、出發／到達及轉車地點；不建議跨站轉乘時間過短的組合。
- 超大字、雙方向大按鈕。每張卡片有「台語慢慢聽」（伺服器上的台語音檔，開播後放慢）和「國語備用」（手機自己的國語）。台語播不出來時，國語按鈕仍然可用。
- 「傳予家人」分享網址，「加到桌面」提供 iPhone Safari 與 Android Chrome 的主畫面安裝教學。
- 支援選日期、時間（放在「家人設定」內，長輩不需要操作）。連不上時，若這台手機存有同一天先前成功的結果，會顯示該結果並標明「資料時間」；沒有同一天的舊資料時，不拿別天的班次來充數。

## 安裝方式
**iPhone：** 使用 Safari 開啟網址，分享圖示（方框向上箭頭）→「加入主畫面」→「加入」。需由使用者自行操作；iOS 網站無法替人自動新增桌面捷徑。

**Android：** 使用 Chrome 開啟網址，點 App「加到桌面」或 Chrome 三點選單→「安裝應用程式／加入主畫面」→確認。

## 資料來源與限制
- 高鐵 **2026/02/02 起適用之常態班表（每週七天）**，2026/10/02 與官方時刻核對過；可能不包含加班／減班、臨時異動、特殊疏運日。以 [台灣高鐵官方網站](https://www.thsrc.com.tw/ArticleContent/a3b630bb-1066-4352-a1ef-58c7b4e8ef7c)為準。畫面上的「高鐵班表依據」直接讀 `data/thsr-weekly.json` 的 `trainSource`，沒有第二份隱藏日期。

### 如何更新高鐵常態班表

1. 打開[台灣高鐵官方時刻](https://www.thsrc.com.tw/ArticleContent/a3b630bb-1066-4352-a1ef-58c7b4e8ef7c)，核對南港↔雲林。
2. 只在官方時刻確實不同時，才改 `data/thsr-weekly.json` 的 `week.south` 與 `week.north`。鍵 `"0"` 到 `"6"` 是星期日到星期六（以臺北中午計算）。每班為 `{"no","dep","arr"}`，24 小時制 `HH:MM`。
3. 同時更新 `version`、`basis`、`trainSource`。`trainSource` 就是畫面上那句話，要寫生效日與這次核對日，並註明不是即時班表。不要把還沒核對的日期寫進去。
4. 執行 `node --test tests/*.test.js`。測試鎖住特定車次（例如 2026-10-14 的 1307、2026-10-16 的 814/818/822/826）。只有官方時刻真的改了，才一起改測試。
5. 公車起站仍於查詢時向公路局索取，不在這個檔案裡。同一日期會在伺服器記憶體與 CDN 保留約 10 分鐘（CDN 過期後最多再沿用 5 分鐘並在背景更新）。過期才重新下載，不會用紙上編的班次填空。
- 公車透過公路局時刻表查詢取得起點站時間。**南公館／虎尾等途中站時間一律為估算，不是公車GPS即時動態**。
- 設定最少高鐵轉公車25分鐘、公車轉乘15分鐘、公車轉高鐵30分鐘的緩衝。仍不保證實際轉乘成功。
- 臨時停駛、國定假日異動須向客運確認。**不識字長輩使用時，建議由家人第一次陪同測試正確站牌位置**。
- 台語使用意傳科技免費展示語音（`/api/taigi`，三段短 MP3、固定台羅）。不是付費語音，可能限流；限流或播不出來時請按同一張卡片的「國語備用」。不會用國語嗓音假裝台語。iPhone 會先要音檔前兩個位元組，伺服器須回 206。
- Vercel Hobby 個人免費方案部署，不需要付費API。自動從 GitHub main 更新。

## 技術
- 靜態 `index.html` + `elder.js` + `elder.css` + PWA manifest/SW。主畫面圖示是 `apple-touch-icon.png`（180）、`icon-192.png`、`icon-512.png`，不再把圖嵌在 HTML。
- `elder.css?v=`、`elder.js?v=` 使用一年快取；改內容時要一起把 `?v=` 與 `sw.js` 的 `CACHE` 名稱加大。HTML 與 `sw.js` 維持短快取。Service Worker 不快取 `/api/`。
- Vercel Node.js Function：`api/schedule.js`（公車）；`api/itineraries.js`（高鐵公車配對）。同一日期快取 10 分鐘。
- `data/thsr-weekly.json`（南港/雲林固定常態週時刻表）
- 測試：`node --test tests/*.test.js`
